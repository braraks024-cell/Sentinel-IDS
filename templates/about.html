ABOUT THIS PROJECT

Deep learning for network traffic

This local educational application uses an Artificial Neural Network (ANN) to classify network traffic. Random Forest and Logistic Regression provide measured baselines.

Limitations

The model learns from the dataset used in training. NSL-KDD is dated and cannot represent all current network traffic. False positives and false negatives will occur; never use this tool as the only security control.

Privacy and safety

Uploaded CSV data is parsed as tabular data, never executed, and removed after analysis. History is private to the logged-in account.
